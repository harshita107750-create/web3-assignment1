## Functions Implemented
1. **`constructor`**: Initializes the contract with team names and minimum bet.
2. **`put_bet(uint team_no)`**: Payable function to place bets on either team.
3. **`close_betting()`**: Restricts the owner from accepting further bets.
4. **`declare_result(uint256 winner)`**: Declares the winning team.
5. **`distribute_amount()`**: Distributes payouts to the winners.
